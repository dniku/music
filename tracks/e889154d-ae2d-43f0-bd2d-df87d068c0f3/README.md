# Мои Ракеты Вверх — «Blown Away»

Проект транскрипции записи с MusicBrainz Recording MBID
[`e889154d-ae2d-43f0-bd2d-df87d068c0f3`](https://musicbrainz.org/recording/e889154d-ae2d-43f0-bd2d-df87d068c0f3).

## Состояние

В [`score.ly`](score.ly) находится первая версия сольной партии, перенесённая из
пользовательского MusicXML. Исходник содержал пять тактов с нотами, пустой
нижний фортепианный стан и ещё 27 пустых тактов. При очистке сохранены тональность
`G major`, размер `4/4`, регистр, знаки альтерации и длительности всех нот.

MusicXML не задавал темп. Для первого прослушивания используется нейтральный
темп `♩ = 120`; его нужно будет сверить с фонограммой.

## Рендеринг

Из корня репозитория:

```console
nix run .#render-moi-rakety-vverh--blown-away
```

Каноническая команда по Recording MBID:

```console
nix run .#render-e889154d-ae2d-43f0-bd2d-df87d068c0f3
```

PDF и MIDI создаются в
`build/e889154d-ae2d-43f0-bd2d-df87d068c0f3/`.
