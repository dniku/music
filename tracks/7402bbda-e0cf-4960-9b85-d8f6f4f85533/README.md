# Атом-76 — «Волки Океана»

Основная партитура — [score.ly](score.ly), общие партии для неё и отдельных
прослушиваний — [music.ily](music.ily).

## Исходная разметка

В пользовательском [тексте](sources/lyrics-with-bar-marks.txt) знак `*`
стоит после слога, на котором начинается сильная доля, а не на границе
такта. Файл сохраняется как исходное свидетельство услышанного ритма;
редактируемая версия текста находится в партитуре.

## Происхождение и ограничения

Вступление основано на пользовательской ABC-транскрипции, раннее соло —
на последовательно уточнявшихся слуховых кандидатах. Ноты и исполнительские
пометки до второго куплета сверены с
[редакцией Михаила Кота](https://codeberg.org/myrrc/music), коммит `8334297`.
Общие партии оставлены отдельно для сборки фрагментов.

Положение одного из акцентов вступления остаётся гипотезой; длительности
аккордов куплетов и припевов ещё предстоит сверить с фонограммой.

Происхождение фонограмм — в [reference/README.md](reference/README.md).
