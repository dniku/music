# Аудиореференсы

Локальное аудио лежит в `reference/audio/` и игнорируется Git. Его идентичность,
хеш и источник зафиксированы в [`recordings.json`](recordings.json), а полная
цепочка получения и преобразований — в корневом
[`ro-crate-metadata.json`](../../../ro-crate-metadata.json).

Референс воспроизводится командой из корня репозитория:

```console
nix run .#fetch-blown-away-reference
```

Соло занимает диапазон `2:22.70–2:33.60` (`142,7–153,6` с). Отдельный MP3 для
прослушивания создаётся так:

```console
nix run .#extract-blown-away-solo
```

Обе команды определены в Git-коммите
`cac941078530dc1b5f2027bf5d9c167beeb9a55e`; его `flake.lock` закрепляет
nixpkgs `1559d3daa3ecc813a650b79375ea61b6741b8746`, `yt-dlp 2026.07.04` и
`FFmpeg 8.1.2`. Команды проверяют SHA-256 входа и результата.

Длительность YouTube-аудио на 10,441 с больше длительности связанной записи в
MusicBrainz (`189,1` с). Поэтому оно пока помечено как связанный, но не
тождественный вариант: название и исполнитель сами по себе не доказывают
совпадение конкретной Recording.
