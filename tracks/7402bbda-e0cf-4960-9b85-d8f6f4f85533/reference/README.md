# Аудиореференсы

Идентификаторы, источники и хеши — в [recordings.json](recordings.json).

Полная запись с вокалом передана пользователем напрямую; предшествующий URL
и команды получения неизвестны. Минус — отдельный микс, поэтому MBID полной
записи указан для него только как связанный референс.

Пользовательский Ogg Opus заменён YouTube WebM после проверки: lossless-remux
содержит те же Opus-пакеты и даёт побитово тот же декодированный PCM.
Временные метки контейнеров начинаются по-разному; выравнивать нужно по звуку.
