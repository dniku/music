# «Волки Океана» — разметка текста

Проект для оформления текста песни группы «Атом-76» в LilyPond с привязкой текста к тактам.

## Исходник

Канонический текст находится в
[`sources/lyrics-with-bar-marks.txt`](sources/lyrics-with-bar-marks.txt).

Знак `*` обозначает момент начала нового такта. Текст после знака относится к новому такту; перевод строки сам по себе тактовую сетку не сбрасывает. Поэтому граница может проходить внутри слова, например `То*лько`.

Размеченный текст является единственным текстовым источником проекта. Правильная строка песни — «Держат путь на небеса».

## Музыкальная сетка

Рабочие параметры, установленные по обеим фонограммам:

- размер — предположительно `6/8`;
- темп — `♩ = 165`, что эквивалентно `♩. = 110`;
- продолжительность такта — приблизительно `1,091` секунды;
- первое «То-» звучит как затакт.

Эти параметры будут окончательно проверены при построении полной тактовой сетки.

## Аудиореференсы

Записи хранятся локально в `reference/audio/` и не добавляются в обычный Git. Их имена, длительности и контрольные суммы зафиксированы в [`reference/README.md`](reference/README.md).

## Состояние

Текст полностью размечен пользовательскими отметками начала такта. Первый макет находится в [`score/volki-okeana.ly`](score/volki-okeana.ly): он сохраняет поэтические строки и заменяет каждую отметку `*` видимой тактовой чертой `│`.

Аккорды пока не перенесены в макет: сначала проверяется представление текста и границ тактов.

## Рендеринг

PDF собирается в `build/volki-okeana.pdf`:

```console
nix run .#render
```

Проверить воспроизводимую сборку в Nix store:

```console
nix flake check
```

Для диагностического PNG можно передать LilyPond дополнительные параметры:

```console
nix run .#render -- --png -dresolution=144
```
