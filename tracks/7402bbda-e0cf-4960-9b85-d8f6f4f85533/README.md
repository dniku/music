# Атом-76 — «Волки Океана»

Проект для оформления текста песни группы «Атом-76» в LilyPond с привязкой текста к тактам.

## Исходник

Канонический текст находится в
[`sources/lyrics-with-bar-marks.txt`](sources/lyrics-with-bar-marks.txt).

Знак `*` стоит после слога, на котором начинается сильная доля такта. При переносе в LilyPond граница ставится перед этим слогом: например, `То*лько тру*сы перед бу*рей *` превращается в `|Только |трусы перед |бурей |`. Отдельная `*` в конце строки задаёт следующую тактовую черту. Бридж имеет собственную группировку `2 + 2 + 3 + 2 + 2 + 3` такта. Слова, продолжающиеся через тактовую черту, соединяются стандартным слоговым дефисом LilyPond (`--`).

Размеченный текст является единственным текстовым источником проекта. Правильная строка песни — «Держат путь на небеса».

## Музыкальная сетка

Рабочие параметры, установленные по обеим фонограммам:

- размер — `4/4`;
- темп — `♩ = 165`;
- продолжительность такта — приблизительно `1,455` секунды;
- первое «То-» приходится на начало первого полного такта вокальной сетки.

Размер подтверждается четырёхдольной группировкой вступления и периодом сильных долей в фонограммах.

## Аудиореференсы

Записи хранятся в DVC, а в обычный Git попадают только DVC-метаданные:
`*.dvc`-указатель для переданной пользователем записи и lock-запись
воспроизводимой стадии для минуса с YouTube. Их имена, длительности и
контрольные суммы зафиксированы в
[`reference/README.md`](reference/README.md), а MusicBrainz и локальные
идентификаторы — в [`reference/recordings.json`](reference/recordings.json).

## Состояние

Основной макет находится в [`score.ly`](score.ly). В нём используются настоящие контексты `Voice`, `Lyrics` и `ChordNames`: отметки `*` сначала переносятся к началу соответствующих слогов, каждый получившийся интервал занимает отдельный такт нотной сетки, а текст связан со скрытым голосом через `\lyricsto`. Текст сильной доли выравнивается от начала такта; затактовые фрагменты после конечной `*` строки привязаны к четвёртой доле начатого этой отметкой такта.

Основная партитура оформлена как двухстановый `PianoStaff`: верхний стан
содержит мелодические партии и направляющую для текста, а нижний стан в
скрипичном ключе — записанные нотами обращения аккордов для левой руки. Названия
аккордов остаются над всей фортепианной системой.

Вступление `0:00.00–0:12.30` перенесено из пользовательской ABC-транскрипции непосредственно в LilyPond и уточнено по прослушиванию. После семи полных тактов следует переходный такт 8 размером `2/4`: последняя `ми` такта 7 продолжается в него лигой; с такта 9 возвращается размер `4/4`. Положение акцента в фонограмме остаётся редакционной гипотезой. Вступление, раннее синтезаторное соло, три повторения подтверждённого соло и черновой гитарный проигрыш встроены в основную нотную сетку. Аккорды куплетов и припевов развёрнуты из схем, записанных в исходном тексте; их точную длительность ещё предстоит сверить с фонограммой.

Ноты и исполнительские пометки до второго куплета сверены с отдельной
[редакцией Михаила Кота](https://codeberg.org/myrrc/music) на коммите
`8334297`. В отличие от неё общие партии остаются в `music.ily`, чтобы из них
собирались отдельные листы и прослушивания. Записанный там 16-тактовый первый
проигрыш механически сжат вдвое до 8 тактов: его высоты и атаки сохранены, а
длительность снова соответствует диапазону примерно `0:59–1:11`.

Номера синтезаторных голосов печатаются в заголовке и у начала секций: `102` —
`lead 2 (sawtooth)`, `463` — `pad 2 (warm)`, `001` — `acoustic grand`. Левая
рука играет голосом `463`; правая переключается между `102` и `463` согласно
секционным пометкам.

## Рендеринг

Из корня репозитория PDF собирается в
`build/atom-76--volki-okeana/score.pdf`. Партитура рассчитана
на четыре страницы портретной A4 и обычно набрана по восемь коротких тактов в
системе; две половины бриджа сохраняют группировку по семь тактов. Между
вступлением и первым куплетом оставлены четыре дополнительные системы: в
первых четырёх тактах каждой действует `Em`, но обозначение и трезвучие
печатаются по-разному: название стоит только в первом такте, а ноты аккорда —
в каждом такте и соединены лигами через тактовые черты. Это же правило
применяется ко всем аккордам партитуры, занимающим несколько тактов. В тактах
5–8 первой и третьей систем стоят
`G | Bm | A | D`, а во второй и четвёртой — `G | F# | G | Em`. Для меньшего
движения левой руки трезвучия первой прогрессии записаны как `соль–си–ре`,
`фа♯–си–ре`, `ми–ля–до♯` и `ре–фа♯–ля`; `F#` во второй прогрессии записан
как `фа♯–ля♯–до♯` между двумя `G = соль–си–ре`.
В тактах `17–24` правая рука в ключе `treble_8` играет последовательность
`B3–E4` (два такта с лигой), `G3–B3` (два такта с лигой), затем по одному
такту `D4–G4 | D♭4–G♭4 | D4–G4 | G3–B3`; в тактах `33–40` она повторяется.
Этот блок обозначен в партитуре как «Вступление 2 / 00:12–00:36» и занимает
такты `9–40`; первый куплет начинается с такта `41`.
Такты основного и отдельных нотных листов имеют сквозную нумерацию от первого
такта соответствующего листа. Номер печатается только в начале каждой нотной
строки; в основной партитуре он не сбрасывается после вступления и
дополнительных систем.
Основная команда воспроизводит также все отдельные прослушивания и оригинальный
фрагмент:

```console
nix run .#dvc -- repro tracks/7402bbda-e0cf-4960-9b85-d8f6f4f85533/dvc.yaml
```

Только партитура:

```console
nix run .#dvc -- repro tracks/7402bbda-e0cf-4960-9b85-d8f6f4f85533/dvc.yaml:render-score
```

Полное прослушивание партитуры создаётся в
`build/atom-76--volki-okeana/full-score.mp3`:

```console
nix run .#dvc -- repro tracks/7402bbda-e0cf-4960-9b85-d8f6f4f85533/dvc.yaml:render-full-score-audition
```

MP3 следует текущей нотной сетке без подрезки по референсу и длится около
`6:05.9`. Это дольше исходной фонограммы (`5:35.7`), поэтому файл предназначен
для прослушивания записанного материала, а не для синхронного наложения на
оригинал. Верхний стан переключается между голосами `102` и `463`, нижний
звучит голосом `463`.

Проверить воспроизводимую сборку в Nix store:

```console
nix flake check
```

Для диагностического PNG низкоуровневой команде можно передать дополнительные
параметры LilyPond:

```console
nix run .#render-atom-76--volki-okeana -- --png -dresolution=144
```
