# Мои Ракеты Вверх — «Blown Away»

Рабочая транскрипция гитарного соло. Канонические высоты, длительности,
тактовая сетка и темп находятся в [`score.ly`](score.ly).

Последовательность высот была перенесена из пользовательского MusicXML, после
чего длительности и несколько нот уточнялись по фонограмме. Ритмический
кандидат № 2 принят как канонический; после A/B-сравнения предпоследняя нота
была сокращена до одной целой. Добавленная в MIDI финальная пауза нужна только
для сохранения полного окна сравнения и в PDF не печатается.

Идентичность YouTube-референса и точный диапазон соло зафиксированы в
[`reference/recordings.json`](reference/recordings.json); пояснение о связи с
MusicBrainz находится в [`reference/README.md`](reference/README.md). Команды
сборки партитуры, MP3 и стереосравнений описаны в
[корневом README](../../README.md) и [`dvc.yaml`](dvc.yaml).
