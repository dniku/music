# Leonard Cohen — Hallelujah

[score.ly](score.ly) — ручной перенос двух фортепианных станов и рукописной аппликатуры из предоставленного пользователем архива Saber. Отдельная вокальная партия, текст и гитарные диаграммы опущены; буквенные аккорды сохранены. В неоднозначной пометке `4 (5)` для последней ноты левой руки в такте 5 выбран основной вариант 4.

MusicBrainz ID относится к оригинальной записи Коэна по выбору пользователя; нотная аранжировка не заявляется точной транскрипцией этой записи. Источник и SHA-256 зафиксированы в [sources/provenance.json](sources/provenance.json); сам архив хранится через DVC, не публикуется на сайте. Пустая пятая страница Saber не переносилась.

PDF сохраняет пять проходов с окончаниями 1–4 и 5; MIDI/MP3 разворачивают их полностью. Числового темпа в источнике нет: рабочий темп воспроизведения — 50 пунктирных четвертей в минуту; `rit.` и ферматы пока только печатные обозначения.
