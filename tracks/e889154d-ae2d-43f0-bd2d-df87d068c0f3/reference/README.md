# Аудиореференс

Идентификаторы, источник и диапазон соло — в [recordings.json](recordings.json).
YouTube-аудио длиннее связанной записи MusicBrainz, поэтому считается
связанным, но не тождественным вариантом. Совпадения названия и исполнителя
недостаточно для присвоения файлу MBID конкретной Recording.
