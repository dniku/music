# Идентичность записи

Каталог относится к основной студийной записи Avantasia — «Lost in Space»:
MusicBrainz Recording
[b0d93aa9-c69d-4b88-8432-1588eea622fc](https://musicbrainz.org/recording/b0d93aa9-c69d-4b88-8432-1588eea622fc).
В качестве конкретного релизного контекста выбран немецкий сингл
*Lost in Space, Part 1* от 15 ноября 2007 года.

MusicBrainz также содержит отдельные Recording MBID для radio edit, alternate,
extended, video и концертных вариантов. Официальный видеоклип связан здесь с
отдельной записью
[8770a32e-b454-4591-9c6f-1bda8b709dcf](https://musicbrainz.org/recording/8770a32e-b454-4591-9c6f-1bda8b709dcf),
но MusicBrainz не связывает с ней конкретный YouTube URL, поэтому точное
тождество не заявляется.

Аудиореференс сохранён без перекодирования: это исходный поток YouTube формата
251 (Opus в контейнере WebM). Команда получения и ожидаемый SHA-256 находятся в
`dvc.yaml`; фактические хэш, длительность и метаданные источника — в
[recordings.json](recordings.json).
