# Аудиореференс

Идентификаторы, длительность, SHA-256, YouTube-источник и диапазон соло
хранятся в [`recordings.json`](recordings.json). Команда получения и её
результат зафиксированы в соседних `dvc.yaml` и `dvc.lock`.

YouTube-аудио длиннее связанной записи MusicBrainz на `10,441` секунды.
Поэтому оно считается связанным, но не тождественным вариантом: совпадения
названия и исполнителя недостаточно, чтобы присвоить файлу MBID конкретной
Recording.
