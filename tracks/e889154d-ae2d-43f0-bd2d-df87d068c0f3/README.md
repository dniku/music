# Мои Ракеты Вверх — «Blown Away»

Редактируемая партитура — [score.ly](score.ly). Последовательность высот соло
перенесена из пользовательского MusicXML, затем уточнена на слух вместе
с длительностями. Текст и аккорды остальных частей предоставлены пользователем.

Финальная пауза в MIDI сохраняет полное окно A/B-сравнения с фонограммой
и намеренно не печатается в PDF.

Происхождение аудиореференса и оговорка о его идентичности —
[reference/README.md](reference/README.md).
