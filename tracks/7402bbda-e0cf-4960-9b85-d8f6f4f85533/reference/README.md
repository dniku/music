Совпадение полной записи подтверждается исполнителем, названием, 2011 годом, номером трека 3 и длительностью около 5:35. В MusicBrainz у записи пока нет ISRC и связи с сущностью Work.

Минусу не присваивается MBID полной записи: отдельный микс считается отдельной Recording. До появления собственной записи в MusicBrainz его точным идентификатором служит SHA-256, а MBID полной версии записан только как связанный музыкальный референс.

Оригинальные аудиофайлы сохраняются неизменными. Для медиатеки следует тегировать их копии из данных `recordings.json`, чтобы не менять зафиксированные SHA-256 референсов.

Оригинальный фрагмент раннего соло `0:58.80–1:10.80` воспроизводимо
извлекается из полной записи в `build/`:

```console
nix run .#extract-volki-early-solo
```

Оба файла были переданы пользователем напрямую. Их предшествующий URL и
команды скачивания или перекодирования неизвестны; это явно зафиксировано в
sidecar-файлах `*.provenance.json` рядом с аудио. Строка
`2Goi7VNlL7I` в имени минуса сохранена только как непроверенная подсказка, а не
как подтверждённый YouTube-источник.
