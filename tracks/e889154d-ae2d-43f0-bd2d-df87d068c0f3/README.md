# Мои Ракеты Вверх — «Blown Away»

Редактируемая партитура — [score.ly](score.ly). Соло перенесено из рукописных нот пользователя с последующими исправлениями; принятый черновик сохранён в [drafts/solo-photo.ly](drafts/solo-photo.ly). Текст и аккорды остальных частей предоставлены пользователем.

Соло при 85 BPM длится `4 × 4 × 60 / 85 ≈ 11,29 с`, поэтому MP3 больше не обрезается до прежнего окна сравнения 10,9 с. Точное выравнивание новой версии с фонограммой ещё не проверено.

## Источники

Идентификаторы, источник и диапазон соло — в [recordings.json](reference/recordings.json).
YouTube-аудио длиннее связанной записи MusicBrainz, поэтому считается
связанным, но не тождественным вариантом. Совпадения названия и исполнителя
недостаточно для присвоения файлу MBID конкретной Recording.
