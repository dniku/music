# Аудиореференсы

Машиночитаемые идентификаторы, длительности, SHA-256 и внешние источники
хранятся в [`recordings.json`](recordings.json). Команды получения и проверки
файлов зафиксированы в соседних `dvc.yaml` и `dvc.lock`.

Полная запись с вокалом была передана пользователем напрямую; предшествующий
URL и команды получения неизвестны. Её соответствие MusicBrainz Recording
подтверждается исполнителем, названием, релизом, номером трека и длительностью.

Минус является отдельным миксом и поэтому не получает MBID полной записи. До
появления собственной Recording его точным идентификатором служит SHA-256, а
MBID полной версии указан только как связанный музыкальный референс.

Прежний пользовательский Ogg Opus был заменён YouTube WebM только после
проверки эквивалентности: lossless-remux содержит те же `16 788` Opus-пакетов
и даёт побитово тот же декодированный PCM. Временные метки контейнеров
начинаются по-разному, поэтому записи следует выравнивать по звуку.
