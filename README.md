# «Волки Океана» — разметка текста

Проект для оформления текста песни группы «Атом-76» в LilyPond с привязкой текста к тактам.

## Исходник

Канонический текст находится в
[`sources/lyrics-with-bar-marks.txt`](sources/lyrics-with-bar-marks.txt).

Знак `*` стоит после слога, на котором начинается сильная доля такта. При переносе в LilyPond граница ставится перед этим слогом: например, `То*лько тру*сы перед бу*рей *` превращается в `|Только |трусы перед |бурей |`. Отдельная `*` в конце строки задаёт следующую тактовую черту. Бридж имеет собственную группировку `2 + 2 + 3 + 2 + 2 + 3` такта. Слова, продолжающиеся через тактовую черту, соединяются стандартным слоговым дефисом LilyPond (`--`).

Размеченный текст является единственным текстовым источником проекта. Правильная строка песни — «Держат путь на небеса».

## Музыкальная сетка

Рабочие параметры, установленные по обеим фонограммам:

- размер — `4/4`;
- темп — `♩ = 165`;
- продолжительность такта — приблизительно `1,455` секунды;
- первое «То-» приходится на начало первого полного такта вокальной сетки.

Размер подтверждается четырёхдольной группировкой вступления и периодом сильных долей в фонограммах.

## Аудиореференсы

Записи хранятся локально в `reference/audio/` и не добавляются в обычный Git. Их имена, длительности и контрольные суммы зафиксированы в [`reference/README.md`](reference/README.md), а MusicBrainz и локальные идентификаторы — в [`reference/recordings.json`](reference/recordings.json).

## Состояние

Основной макет находится в [`score/volki-okeana.ly`](score/volki-okeana.ly). В нём используются настоящие контексты `Voice`, `Lyrics` и `ChordNames`: отметки `*` сначала переносятся к началу соответствующих слогов, каждый получившийся интервал занимает отдельный такт нотной сетки, а текст связан со скрытым голосом через `\lyricsto`. Текст сильной доли выравнивается от начала такта; затактовые фрагменты после конечной `*` строки привязаны к четвёртой доле начатого этой отметкой такта.

Вступление для синтезатора перенесено из пользовательской ABC-транскрипции непосредственно в LilyPond. Аккорды куплетов и припевов развёрнуты из схем, записанных в исходном тексте; их точную длительность ещё предстоит сверить с фонограммой.

## Рендеринг

PDF собирается в `build/volki-okeana.pdf`. Партитура рассчитана на две страницы портретной A4 и набрана по восемь коротких тактов в системе; две половины бриджа сохраняют группировку по семь тактов:

```console
nix run .#render
```

Проверить воспроизводимую сборку в Nix store:

```console
nix flake check
```

Для диагностического PNG можно передать LilyPond дополнительные параметры:

```console
nix run .#render -- --png -dresolution=144
```
